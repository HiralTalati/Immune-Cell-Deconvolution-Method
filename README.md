**Hub Gene & Immune Cell Deconvolution Association Analysis Pipeline**

This repository contains an end-to-end bioinformatics pipeline written in R for integrating hub gene expression matrices with immune cell abundance scores generated by ImmuCellAI. The pipeline performs high-throughput Spearman rank correlation testing, applies Benjamini-Hochberg multiple-testing corrections (FDR), stratifies critical immunological associations, and generates annotated heatmaps.

📌 Features

• Automated Package Management: Dynamically audits, downloads, and mounts required CRAN packages (tidyverse, pheatmap, ggpubr, openxlsx).

• Matrix Re-shaping & Synchronization: Transposes standard gene-centric expression matrices (genes as rows, samples as columns) into long clinical formats, cross-maps sample identifiers against deconvolution scores, and drops mismatched arrays.

• Strict Integrity Auditing: Screens variables across datasets to confirm they are strictly numerical vectors, preventing calculation errors before running statistical loops.

• FDR-Adjusted Spearman Correlation: Runs non-parametric Spearman rank correlation tests across all pairs of hub genes and immune populations, filtered for data availability (N ≥ 10 paired samples), and adjusts p-values via the Benjamini-Hochberg (BH) method.

• Significance-Annotated Heatmaps: Pivots data into wide-format matrices to generate a clean, unclustered association map using pheatmap. It dynamically overlays asterisks matching standard academic thresholds ($*: \(\text{FDR} < 0.05\), **$: FDR < 0.01, \(***\): FDR < 0.001).

🛠️ Tech Stack & Dependencies

The computational workflow runs natively inside an R environment (v4.0+).

Required Libraries:

tidyverse, readr, ggplot2, pheatmap, RColorBrewer, ggpubr, openxlsx

📂 Input Dataset Specifications

Before running the script, ensure your local directory contains the following two Excel/spreadsheet structures (update the file paths in sections 3 and 4 of the script to match your working workspace):

1. ImmuneCellAbundance_sample.xlsx: Mout from the ImmuCellAI web server or pipeline. Must feature a column named sample containing your Sample Accession IDs alongside numeric fractional cell abundance features.

2. BCT_Expr_Matrix_Symbol_hubgenes.xlsx: An batch corrected expression matrix filtered for your target biomarkers. The first column must contain the Gene Symbols, while the remaining column headers map directly to the Sample IDs.

Target Hub Genes Evaluated (N=10) for current work:

NDUFS5, NDUFA1, NDUFB3, COX7A2, ATP5ME, UQCRH, UQCRHL, TOMM7, ATP6V1E1, SLIRP

🚀 Execution Workflow

To run the complete pipeline (data preparation, merge, correlation testing, and heatmap plot generation), execute the script from your terminal or an integrated development environment:

Rscript immune_hub_correlation_pipeline.R

3. **Immune Cell Deconvolution Disease-Stage Profiling**

To track systematic shifts in cellular microenvironments across Alzheimer's disease progression, the pipeline incorporates a disease-stage profiling module (immucellai_disease_stage.R) that models the abundance of 24 immune cell lineages across 1,301 clinical samples.

Key features and statistical specifications of this module include:

• Cohort Harmonization & Recoding: Merges the raw cell fractions matrix with sample clinical metadata, filtering explicitly for the target cohorts, and recodes borderline patient samples into the MCI group to build three robust factor groups (CTL: 487, MCI: 326, AD: 488).

• Non-Parametric Multi-Group Modeling: Performs high-throughput Kruskal-Wallis H-testing across all 24 deconvoluted cell populations to evaluate global fractional distribution variances between the clinical groups.

• Multiple-Testing Correction & Post-Hoc Stratification: Controls false discovery rates using the Benjamini-Hochberg (BH-FDR) method. For cell types meeting the strict significance threshold (\(\text{FDR} < 0.05\)), the script initiates Dunn’s Post-Hoc pairwise test adjusted via BH to isolate specific stage-to-stage transition patterns.

• Exploratory Distribution Plotting: Generates composite cross-cohort violin plots overlaying internal boxplots with custom HEX hex-codes (CTL: #4C78A8, MCI: #F2A541, AD: #D95F59) for the top 6 strongest nominally changing immune cell signatures.
